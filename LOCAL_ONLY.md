# WM Keyboard — Local-only fork profile

This fork adds a strict local-only build profile. It is deliberately separate
from the upstream Standard, F-Droid and Offline builds.

## Build

From the repository root, with Android SDK, NDK and the pinned build tools installed:

```sh
./gradlew :app:assembleIntlRelease -Pwmkb.localOnly=true
```

To run the app unit tests under the same profile:

```sh
./gradlew :app:testIntlDebugUnitTest -Pwmkb.localOnly=true
```

## What the profile enforces

- Removes `INTERNET` from the **merged APK manifest**, including declarations
  contributed by dependencies. Android's network-state and Wi-Fi discovery
  permissions remain so the existing offline paths do not crash while inspecting
  connectivity; without `INTERNET`, the app cannot open IP sockets.
- Uses the F-Droid source set to omit Google Play Services and ML Kit code.
  Local GGUF inference, offline dictionaries, offline grammar, Tesseract OCR
  and supported on-device speech engines remain available where their runtime
  is bundled.
- Clears every build-injected external API key and cloud OAuth client ID.
- Disables location permission and location-dependent features in this build.
- Exposes only provider types explicitly marked as on-device. Cloud APIs,
  public endpoints and user-configured self-hosted HTTP endpoints are not offered
  or resolved, including Ollama and LM Studio servers.
- Disables runtime native-library pin downloads and bundles the native libraries
  selected by the build.
- Removes the cloud OAuth redirect activity and scheduled cross-device sync
  service. Local-folder backup remains available.

## Models and language packs

The profile does not silently fetch model weights. Import model files from
device storage using the app's local import flow. No model is downloaded by
the app in this profile.

### Hinglish speech recognition

The bundled `whisper.cpp` runtime supports these optional GGML models:

- **AirNote Swift Hinglish Q8_0** (~78 MB), file
  `ggml-oriserve-hinglish-q8_0.bin`. Hindi fine-tune; greedy decoding is used
  to reduce latency. It is offered for Hindi dictation.
- **Apex Hinglish Q8_0** (~834 MB), file
  `ggml-apex-hinglish-q8_0.bin`. Large-v3-Turbo fine-tune for Hindi/English
  Hinglish; model-side language detection is retained.

Download the Q8_0 file manually from the corresponding Hugging Face repository,
then open Voice typing → Whisper → Import and select the `.bin` file. The
importer checks the expected filename, a bounded file-size range and whether
the bundled Whisper runtime can load the GGML model. A model will appear as a
voice engine only after it has been imported. Both produce Romanized Hinglish,
not Devanagari.

The Android system speech recognizer is not offered in this profile because it
runs in another app and may use a remote service. Select an imported local model
or another bundled on-device engine instead.

## Important boundary

The Android APK is built on a development machine that needs access to the
Gradle repositories and Android toolchain unless those dependencies are already
cached. The runtime permission lockdown applies to the installed app, not to the
developer's build machine.

This profile is designed to prevent the app from opening Internet or local-IP
network sockets through Android's normal networking APIs. It does not claim to
disable unrelated operating-system connectivity or traffic generated by other
apps on the device.
